# Educacy 侧边栏版设计稿

## 说明
- 此版本专门针对 Chrome Side Panel 尺寸（约 360-390px）重绘。
- 与之前全盘重构稿独立目录，不覆盖旧版本。

## 文件
- `index.html`：总览入口
- `rubric-sidepanel.html`：细则模块
- `grading-sidepanel.html`：阅卷模块
- `records-sidepanel.html`：记录模块
- `settings-sidepanel.html`：设置模块
- `shared.css`：统一样式 token 与组件样式

## 评审重点
1. 信息密度在 360px 宽度下是否仍可读
2. 顶栏/内容/底部导航三段式是否符合实际侧边栏操作习惯
3. 是否保留当前业务动作优先级（主要 CTA 位置）
