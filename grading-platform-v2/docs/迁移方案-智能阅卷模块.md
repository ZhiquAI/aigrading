> 文档版本：v1.0

> 目标项目：grading-platform-v2
> 创建时间：2026-02-15

## 1. 迁移概述

### 1.1 迁移目标

将 **ai-智能批改助手_副本** 中的完整智能阅卷功能迁移到 **grading-platform-v2**，包括：

1. **前端状态管理**：GradingContext、状态机、自动阅卷会话
2. **评分服务增强**：学科专项规则、整数分值校验、评语优化
3. **会话管理**：断点续批、去重检测、性能监控
4. **页面交互**：答题卡抓取、分数回填、平台适配

### 1.2 迁移范围

| 模块 | 源文件 | 目标位置 |
|------|--------|----------|
| 评分服务 | `services/grading-service.ts` | `packages/domain-core` 或 `apps/api-server` |
| 状态机 | `hooks/useGradingMachine.ts` | `packages/domain-core` 或前端 store |
| 自动会话 | `hooks/useAutoGradingSession.ts` | 前端 store |
| 页面上下文 | `hooks/usePageContext.ts` | `packages/extension-bridge` |
| 会话管理 | `services/grading-session.ts` | 前端 store |
| 常量配置 | `constants/grading.ts` | `packages/domain-core` 或共享配置 |
| UI组件 | `components/GradingViewV2.tsx` 等 | `apps/extension-app` |

### 1.3 迁移策略

采用 **渐进式迁移** 策略：

```
Phase 1: 基础设施迁移（共享类型和常量）
    ↓
Phase 2: 评分服务增强（学科规则、校验逻辑）
    ↓
Phase 3: 前端状态管理（状态机、会话管理）
    ↓
Phase 4: UI 组件迁移（完整阅卷界面）
    ↓
Phase 5: 集成测试与优化
```

**3.1.2 整数分值校验**

在现有 `grading-service.ts` 中增强校验逻辑：

```typescript
// apps/api-server/src/modules/grading/grading-service.ts

/**
 * 标准化评分结果 - 确保整数分值
 */
function normalizeGradingResult(raw: unknown): StudentResult {
    // 1. 强制整数化所有分值
    const score = Math.round(Number(raw.score) || 0);
    const maxScore = Math.round(Number(raw.maxScore) || 0);

    // 2. 处理 breakdown
    const breakdown = normalizeBreakdown(raw.breakdown);

    // 3. 校验总分与明细一致
    const breakdownSum = breakdown.reduce((sum, item) => sum + item.score, 0);
    const finalScore = Math.min(score, breakdownSum);

    // 4. 截断评语长度
    const comment = truncateComment(raw.comment, 80);

    return {
        id: generateId(),
        name: raw.studentName || '考生',
        score: finalScore,
        maxScore,
        comment,
        breakdown
    };
}

/**
 * 评语去重和长度控制
 */
function deduplicateComment(text: string, maxLength: number = 80): string {
    if (!text) return '';

    // 检测重复模式
    const words = text.split(/[，。,.\s]+/).filter(w => w.length > 2);
    const seen = new Map<string, number>();

    for (const word of words) {
        const count = (seen.get(word) || 0) + 1;
        seen.set(word, count);
        if (count >= 3) {
            // 找到重复位置，截断
            return text.substring(0, text.indexOf(word)).trim() + '...';
        }
    }

    // 长度截断
    if (text.length > maxLength) {
        return text.substring(0, maxLength).trim() + '...';
    }

    return text;
}
```

**4.1.2 会话管理**

```typescript
// apps/extension-app/src/store/grading-session-store.ts

import { create } from 'zustand';
import { persist } from 'zustand/middleware';

interface GradingSessionState {
    session: GradingSession | null;
    isResumable: boolean;

    // Actions
    createSession: (questionKey: string, questionNo: string, platform?: string) => void;
    resumeSession: () => void;
    pauseSession: (reason?: string) => void;
    completeSession: () => void;
    recordGraded: (signature: string) => void;
    clearSession: () => void;
}

export const useGradingSessionStore = create<GradingSessionState>()(
    persist(
        (set, get) => ({
            session: null,
            isResumable: false,

            createSession: (questionKey, questionNo, platform) => {
                set({
                    session: {
                        id: generateSessionId(),
                        questionKey,
                        questionNo,
                        startTime: Date.now(),
                        lastActivityTime: Date.now(),
                        gradedCount: 0,
                        lastGradedSignature: '',
                        status: 'active',
                        platform
                    },
                    isResumable: false
                });
            },

            resumeSession: () => {
                const { session } = get();
                if (session && (session.status === 'paused' || session.status === 'interrupted')) {
                    set({
                        session: { ...session, status: 'active', lastActivityTime: Date.now() },
                        isResumable: false
                    });
                }
            },

            pauseSession: (reason) => {
                set((state) => ({
                    session: state.session ? {
                        ...state.session,
                        status: 'paused',
                        interruptReason: reason,
                        lastActivityTime: Date.now()
                    } : null
                }));
            },

            completeSession: () => {
                const { session } = get();
                if (session) {
                    console.log(`会话完成：共批改 ${session.gradedCount} 份`);
                }
                set({ session: null, isResumable: false });
            },

            recordGraded: (signature) => {
                set((state) => ({
                    session: state.session ? {
                        ...state.session,
                        gradedCount: state.session.gradedCount + 1,
                        lastGradedSignature: signature,
                        lastActivityTime: Date.now()
                    } : null
                }));
            },

            clearSession: () => set({ session: null, isResumable: false })
        }),
        {
            name: 'grading-session-storage',
            partialize: (state) => ({ session: state.session })
        }
    )
);
```
