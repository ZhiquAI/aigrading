# Ant Design 设计稿对比说明

## 文件清单
- `index.html`：总览入口
- `draft-a-luminous-academy.html`：专业教学感（推荐默认主题）
- `draft-b-command-grid.html`：高对比效率风
- `draft-c-aurora-flow.html`：AI Native 品牌风
- `draft-d-educacy-replica.html`：基于 Dribbble Educacy 风格的高还原稿

## 快速决策建议
- 如果你要“稳健上线 + 降低迁移风险”：选 **A**
- 如果你要“重度用户效率优先”：选 **B**
- 如果你要“强品牌辨识 + AI 感”：选 **C**
- 如果你要“接近参考站视觉语气”：选 **D**

## 评审建议（5项）
1. 第一眼是否有记忆点？
2. 文字层级是否一眼可扫读？
3. 卡片与筛选区是否不拥挤？
4. 是否符合老师使用时的专业感预期？
5. 是否能接受该方向作为 Antd 主题基线？
